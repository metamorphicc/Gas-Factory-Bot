# Telegram Document Assistant MVP

Демо-MVP Telegram-бота для работы с клиентскими папками и Word-шаблонами.

## Возможности

- добавить клиента и создать локальную папку `data/clients/<client_name>/`
- загрузить файл клиента: `pdf`, `doc`, `docx`, `jpg`, `png`
- посмотреть папки клиентов и скачать файл обратно
- заполнить `.docx` шаблон по найденным полям `{{field}}`
- сохранить готовый документ в папку клиента и отправить его в чат

## Запуск

```bash
pip install -r requirements.txt
```

Создайте `.env` рядом с `main.py`:

```env
BOT_TOKEN=your_telegram_bot_token
```

Запустите:

```bash
python main.py
```

## Папки

- `templates/` - Word-шаблоны `.docx`
- `data/clients/` - локальные папки клиентов

В проекте есть демо-шаблон `templates/demo_client_form.docx` с полями:

- `{{full_name}}`
- `{{passport}}`
- `{{inn}}`
- `{{date}}`

## Безопасность

Это MVP demo для клиента, не production IAM. Первый Telegram-пользователь, который запустил бота, становится владельцем демо-сессии; остальные пользователи не смогут просматривать локальные папки. Файлы ограничены по типу и размеру, имена папок и файлов очищаются перед сохранением.
